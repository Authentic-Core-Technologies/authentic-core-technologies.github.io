# authentic-core-technologies.github.io

Public site for Authentic Core Technologies apps (GitHub Pages).

- `app-ads.txt`: one file for all apps (AdMob publisher ID). Add a line only when adding another ad network.
- `<app-slug>/privacy/index.html`: one privacy policy per app. For a new app, copy a folder, change the texts, and add it to `index.html`.
- aQRnym's policy lives in its own repository (`aqrnym-privacy`) and is served at `/aqrnym-privacy/`.

Source of the Keep the Ball Rolling text: `whiteCollarGames/mobile/store-assets/PRIVACY_POLICY.md`.
